# hxyfront-62014 赛鸽训放记录

源提示词编号：9

面向赛鸽棚的训放记录前端工具，核心是一台**日志合并台**：

- **粘贴 → 预览 → 确认写入**：鸽棚导出的训放表格式不一（制表符/逗号/空格分隔、表头顺序随意、日期写法多样），粘贴后先解析预览，确认才落库。
- **按足环 + 放飞时刻判重**：重复行不写入，沿用首次来源；同批次内先出现的占坑。
- **待补区**：缺放飞距离、天气或归巢时刻的记录留在待补，不进排行；补齐后自动入榜。
- **修改留痕**：改动距离、天气或报时会重算排行，并留下前后值与名次变化。
- **跟随当前结果**：鸽棚总览、未归巢数量、血统档案、单羽档案全部由当前记录实时推导。

代码分层：`src/lib/parser.ts`（表格解析）、`src/lib/merge.ts`（合并判断/排行/留痕）、`src/lib/store.ts`（界面动作 reducer + 本地持久化）、`src/components/*`（界面）。
