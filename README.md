# hxyfront-62014 赛鸽训放记录

源提示词编号：9

我想做一个面向赛鸽棚的训放记录前端工具，鸽主可以记录足环号、血统、训放地点、放飞距离、天气、归巢时间、飞行速度、健康状态和配对记录。页面需要有鸽棚总览、训放成绩排行、未归巢提醒、单羽赛鸽档案和按血统筛选的历史成绩。

## 技术栈

React + Vite + TypeScript

## 功能说明

- **日志合并台**：粘贴各棚导出的训放表（制表符/逗号/竖线分隔、列顺序不限、可含表头），先预览再确认写入。
- **合并判读**：按足环号 + 放飞时刻识别重复，重复行沿用首次来源；缺距离、天气或归巢时刻的行留在待补区，不进排行。
- **排行与修订**：改动距离、天气或归巢报时会重算排行，并在修订记录中保留前后值与名次变化。
- **联动面板**：总览、未归巢数量、血统档案均按当前有效记录实时计算；待补行可补全入库或标记未归巢。

## 代码分层

- `src/lib/parse.ts`：表格解析（分隔符探测、表头别名、无表头按内容推断列、足环/时刻/距离/天气识别）。
- `src/lib/merge.ts`：合并判断（去重键、待补判定、排行计算、改数留痕），全部为纯函数。
- `src/App.tsx` + `src/components/`：界面动作，只编排纯函数并落状态（localStorage 持久化）。
